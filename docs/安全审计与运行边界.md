## Linux 新增控制

无提权、无 shell 客户端执行；时区限于固定清单/偏移；检查桌面 ELF、安装资源及目标目录写权限；配置目录私有、原子保存且拒绝链接；已有客户端停止启动；明确区分进程启动与窗口/时区显示验证。网络逐块限额、HTTPS-only、超时、手动触发；不使用发现的凭据，也不读取客户端会话数据。

原桌面入口复用只读取当前用户或 root 拥有、组/其他用户不可写的普通文件，限 64 KiB。Exec 作为数据解析，拒绝未知程序、shell 操作符、无法支持的激活方式；实际仍直接执行验证后的客户端 ELF。原入口显式设置保留，TZ 和三个启动器加载变量除外。检查诊断只返回环境变量名称与一致性布尔值；不输出完整 Exec、代理值或登录内容。这些控制属于新增 Linux 实现，不冒充上游静态审计覆盖。

v0.1 打包运行库与 GTK 输入法模块，私有模块缓存仅用于启动器；启动原客户端前移除该私有 GTK_IM_MODULE_FILE 与 CODEX_TZ_RUNTIME_CACHE，原入口的显式输入法设置仍优先。deb 无维护脚本，不自动启动、不读取/修改原账户数据。解压运行验收检查实际进程映射，防止仅 ldd 通过却仍从构建目录动态加载模块。
